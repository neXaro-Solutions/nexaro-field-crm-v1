# neXaro Field CRM V1

Mobile-first PWA für den Außendienst.

Enthalten:
- Lead-Erfassung/Bearbeitung
- Pipeline und Filter
- Follow-ups mit Fälligkeit
- Besuchsnotizen
- Telefon/Navigationslinks
- Standortanzeige
- CSV-Export
- JSON-Backup/Restore
- Demo-Daten
- Offline-Caching/PWA

Die V1 speichert lokal im Browser. Für eine echte Team-Version können später Login, Cloud-Sync, Rollen, zentrale Reports und eine gemeinsame Datenbank ergänzt werden.
