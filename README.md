# neXaro Field CRM V1.0

Mobile-first PWA für den Außendienst.

## Module
- Dashboard/KPIs
- Lead CRM mit TPV und interner A/B/C/D-Qualifizierung
- Besuchsnotizen, Telefon, Maps
- Follow-ups/Tasks
- Gebiet: Standort oder PLZ/Ort, Radius, gespeicherte Leads, lokale Routenreihenfolge
- OpenStreetMap/Overpass-Recherche potenzieller Unternehmen
- SumUp Tarifvergleich
- interne Provisionskalkulation
- CSV und JSON Backup/Restore
- Demo-Daten
- PWA/Service Worker/offline

## Deployment
Dateien ins Root eines öffentlichen GitHub-Repositories laden und GitHub Pages auf `main` / `/root` stellen.

## Hinweis
CRM-Daten werden lokal im Browser gespeichert. Regelmäßig JSON-Backups exportieren.
