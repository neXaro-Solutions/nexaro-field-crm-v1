# neXaro Field CRM V1.1

Mobile-first PWA für den Außendienst von neXaro Solutions.

## Vertriebsprozess
Lead → Qualifizierung → Besuch → Follow-up → Angebot → Rechnung → Abschluss.

## Enthalten
- Lead CRM mit TPV und interner Qualifizierung
- Sales Assistant und SumUp Tarifvergleich
- Gebietssuche, OSM-Potenziale, Route und Google Maps Übergabe
- Besuchsprotokoll und Tasks
- Angebots- und Rechnungserfassung mit E-Mail-Übergabe
- Interner Provisionsrechner
- CSV Export und JSON Backup/Restore
- PWA/offlinefähige Grundstruktur

Provisionen sind ausschließlich intern. Kundenseitige Dokumente enthalten keine Provisionsdaten.
